Epstein Bench

A verified RAG benchmark over the full public Epstein Files release — noisy, OCR'd, entity-rich.

Systems answer investigator-style questions over the public Epstein Files corpus and must cite the documents that support each answer. The headline metric is cited answer correctness: an answer counts only when a pinned LLM judge accepts it and a cited document is in the pooled gold set. Every task passed a four-stage verification gauntlet before release. See the methodology and dataset card.
